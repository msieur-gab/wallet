Notes for a healthcare setting

  • Always use a challenge (nonce) and domain (audience) when requesting a VP to prevent replay.
  • Prefer did:web or did:ion for registered org issuers; keep did:key for ephemeral/dev.
  • For true data‑minimization, use SD‑JWT VCs or BBS+ signatures for unlinkable selective disclosure.
  • Store keys in a secure enclave where possible; never transmit private keys to third parties.
